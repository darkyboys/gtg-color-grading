## LUTs (Look Up Tables)
What are they ? They are basically a file containing information about Transforming one color into another. For example a lut can have information about Converting the RED Color into Blue. So when you apply them in a software. The software uses that information to convert RED Color into Blue.

The explanation above is a simplified explanation about the LUTs how ever the luts you will find here does a more complex color transformations to give you the looks that you want in your footage.

| **File** | **Purpose** |
|---|---|
| `GTG Color Science.cube` | Gives those pleasing teal and orange shades, along with soft light and pleasing skin tones. |
| `GTG Color Science Desaturator.cube` | Desaturates everything except warm colors. |
| `GTG Color Science v2.cube` | Same as `GTG Color Science.cube`, but adds a proper cool tint to the highlights. Highly recommended for rainy, ARRI-like, classic cinema looks. |
